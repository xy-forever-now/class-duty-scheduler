# 班级工作台 - 智能排班系统

一个纯前端实现的班级值班表自动生成工具，支持Excel导入、智能排班、导出和打印。

## ✨ 核心功能

- 📥 **Excel导入**：支持 `.xlsx` 和 `.xls` 格式，自动识别姓名、性别列
- 🎲 **智能排班**：
  - 自动按性别均衡分配
  - 体力活（扫地/倒垃圾）优先男生
  - 公平算法：每人分配次数最少优先
  - 支持单周/双周/四周轮换
- 📤 **导出Excel**：一键导出多周值班表
- 🖨️ **打印支持**：优化的打印样式，A4纸张友好

## 🚀 使用方法

1. **双击打开 `index.html`**（推荐使用 Chrome / Edge / Firefox 浏览器）
2. 点击「📥 导入Excel」上传您截图中的值班表文件
3. 配置起始日期、排班周期、分配策略
4. 点击「🎲 生成值班表」
5. 点击「📤 导出Excel」或「🖨️ 打印」

## 📋 Excel 文件格式要求

参考您截图中的格式：

| 星期 | 职务 | 姓名 | 性别 | 姓名 | 性别 |
|------|------|------|------|------|------|
| 周一 | 扫地 | 田志远 | 男 | 夏广洋 | 男 |
| 周一 | 扫地 | 尚依娜 | 女 | 庹楚欣 | 女 |
| ... | ... | ... | ... | ... | ... |

**注意**：
- 第一行必须是表头，包含"姓名"和"性别"列
- 系统会自动跳过"星期"和"职务"列
- 支持两张学生名单表格（左右并排）

## ⚙️ 排班配置说明

| 配置项 | 说明 |
|--------|------|
| 起始日期 | 排班从哪个周一开始 |
| 排班周期 | 单周/双周/四周轮换 |
| 分配策略 | 均衡分配（推荐）/ 随机 / 按性别优先 |
| 每日职务 | 可自定义勾选需要的职务类型 |

## 📝 算法说明

**排班公平性保证**：
- 维护 `assignedCount[name]` 计数
- 每次选择分配次数最少的学生
- 同一周内不会重复选同一人
- 性别比例均衡（男生女生轮流优先）

**示例**：班级40人（20男20女），单周5天×4职务=20个岗位
- 第一周：男生10岗 + 女生10岗
- 第二周：剩余人员继续，分配次数最少优先
